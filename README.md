## 📖 Sobre o projeto

O **Power Lava-Car** é um site institucional desenvolvido para apresentar os serviços de lavagem e estética automotiva de maneira moderna, profissional e acessível.

A página permite que os clientes conheçam os serviços disponíveis, consultem valores, montem pacotes personalizados e realizem solicitações de agendamento diretamente pelo WhatsApp.

O projeto foi desenvolvido com foco em:

- Experiência do usuário
- Apresentação profissional do negócio
- Facilidade de navegação
- Conversão de visitantes em clientes
- Funcionamento em celulares e computadores
- Integração direta com o atendimento comercial

## 🎯 Objetivo do projeto

O objetivo foi criar uma presença digital completa para a **Power Lava-Car**, reunindo em um único local:

- Apresentação da empresa
- Lista de serviços
- Valores
- Informações de contato
- Localização
- Agendamento
- Integração com WhatsApp
- Conteúdo visual
- Depoimentos
- Informações sobre o funcionamento

Mais do que uma página visual, o projeto funciona como uma ferramenta comercial para facilitar o contato entre a empresa e seus clientes.

## 🧩 Seções do site

### 🏠 Apresentação

A primeira seção apresenta a identidade da Power Lava-Car, sua proposta de serviço, vídeo em destaque e botão para agendamento.

Também são exibidos indicadores relacionados à experiência e aos atendimentos realizados.

### 🚿 Serviços

A seção de serviços apresenta opções como:

- Lavagem expressa
- Lavagem completa
- Cera cristalizadora
- Higienização interna
- Polimento de faróis
- Serviço leva e traz

Cada serviço possui descrição e valor correspondente.

### 🧮 Pacote personalizado

O cliente pode selecionar diferentes serviços e acompanhar o valor total sendo atualizado automaticamente.

Após finalizar sua escolha, o site prepara uma solicitação completa para envio pelo WhatsApp.

### 📅 Agendamento

O formulário permite informar:

- Nome
- Telefone
- Serviço desejado
- Data
- Opção de leva e traz

Antes do envio, o site valida os dados e apresenta o valor estimado do atendimento.

### 🎥 Conteúdo visual

O projeto utiliza vídeos integrados para apresentar o negócio e demonstrar o processo de cuidado com os veículos.

### ⭐ Depoimentos

A seção de avaliações foi criada para reforçar a confiança e apresentar experiências relacionadas ao atendimento.

### 📍 Localização

A seção de localização reúne:

- Endereço
- Telefones
- E-mail
- Horários
- Status aberto ou fechado
- Google Maps
- Botão para traçar rota
